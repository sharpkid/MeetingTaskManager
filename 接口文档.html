腾讯会议挂机任务管理系统 - 接口文档

一、概述

本系统采用会议任务与挂机任务分离的设计模式：

  • 会议任务：代表一个腾讯会议，包含会议号、密码、时间等信息
  • 挂机任务：对应会议的一个挂机名额，移动端认领和执行的对象

二、客户端接口（移动端使用）

1. 设备注册

POST /api/client/register

功能：设备首次注册

请求参数（form-data）

参数类型必填说明
device_idstring是设备唯一标识（建议使用UUID或IMEI）
device_modelstring是设备型号（如 iPhone 15 Pro）
system_versionstring是系统版本（如 iOS 17.0）
has_tencent_meetingint是是否安装腾讯会议（1=是，0=否）

响应示例

{
    "code": 200,
    "msg": "操作成功",
    "data": {
        "is_success": true,
        "device_status": "free"
    }
}

2. 获取可领取任务列表

GET /api/client/task/list

功能：获取可领取的挂机任务列表

请求参数（URL参数）

参数类型必填说明
device_idstring是设备ID

响应示例

{
    "code": 200,
    "msg": "操作成功",
    "data": {
        "task_list": [
            {
                "hangup_task_id": "3865d297-6e77-4a12-aa8d-7e88a2f18773",
                "meeting_task_id": "339c78ca-f831-4d64-933a-48b5ffae82ec",
                "meeting_code": "123456789",
                "meeting_pwd": "123456",
                "start_time": "2026-06-08 14:00:00",
                "end_time": "2026-06-08 15:00:00",
                "priority": 1
            }
        ]
    }
}

3. 领取挂机任务

POST /api/client/task/receive

功能：领取一个挂机任务

请求参数（form-data）

参数类型必填说明
device_idstring是设备ID
hangup_task_idstring是挂机任务ID

响应示例（成功）

{
    "code": 200,
    "msg": "操作成功",
    "data": {
        "is_receive_success": true,
        "fail_reason": "",
        "task_detail": {
            "hangup_task_id": "3865d297-6e77-4a12-aa8d-7e88a2f18773",
            "meeting_task_id": "339c78ca-f831-4d64-933a-48b5ffae82ec",
            "meeting_code": "123456789",
            "meeting_pwd": "123456",
            "start_time": "2026-06-08 14:00:00",
            "end_time": "2026-06-08 15:00:00"
        }
    }
}

4. 心跳上报

POST /api/client/heartbeat

功能：定时上报设备状态（建议每15秒一次）

请求参数（form-data）

参数类型必填说明
device_idstring是设备ID
device_statusstring是设备状态（free/running）
current_task_idstring否当前执行的挂机任务ID
in_meetingstring否是否在会议中（true/false）
network_statusstring否网络状态（normal/weak/offline）

5. 会议状态上报

POST /api/client/task/report-status

功能：上报入会结果

请求参数（form-data）

参数类型必填说明
device_idstring是设备ID
hangup_task_idstring是挂机任务ID
in_meetingstring是是否入会成功（true/false）
status_msgstring否状态描述

6. 完成挂机任务

POST /api/client/task/complete

功能：完成挂机任务

请求参数（form-data）

参数类型必填说明
device_idstring是设备ID
hangup_task_idstring是挂机任务ID

7. 异常退出

POST /api/client/task/error-exit

功能：异常退出挂机任务（任务回收，允许其他设备领取）

请求参数（form-data）

参数类型必填说明
device_idstring是设备ID
hangup_task_idstring是挂机任务ID
error_msgstring是错误描述

三、管理端接口

1. 发布会议任务

POST /api/server/task/publish

功能：发布会议任务，自动创建对应数量的挂机任务

请求参数（form-data）

参数类型必填说明
meeting_codestring是腾讯会议号
meeting_pwdstring否会议密码
start_timeint是开始时间戳（秒）
end_timeint是结束时间戳（秒）
need_numint是需要挂机人数
priorityint否优先级（默认1）
remarkstring否备注

2. 取消会议任务

POST /api/server/task/cancel

功能：取消会议任务（所有关联挂机任务一并取消）

请求参数（form-data）

参数类型必填说明
meeting_task_idstring是会议任务ID

3. 设备统计

GET /api/server/stats/device

功能：获取设备统计信息

4. 任务统计

GET /api/server/stats/task

功能：获取会议任务和挂机任务统计

四、数据结构说明

1. 会议任务状态

状态值中文描述说明
pending待开始会议尚未开始，挂机任务可领取
running进行中有设备已领取并执行挂机任务
completed已完成所有挂机任务都已完成
canceled已取消管理员取消或超时自动取消

2. 挂机任务状态

状态值中文描述说明
wait_receive待领取等待设备领取
running进行中设备已领取并执行中
completed已完成设备完成挂机任务
canceled已取消关联的会议任务被取消

3. 设备状态

状态值中文描述说明
free空闲设备未执行任何任务
running运行中设备正在执行挂机任务

五、移动端开发注意事项

  • 网络请求：使用HTTPS，设置合理超时（建议30秒），失败重试（最多3次）
  • 心跳机制：间隔15秒，连续3次失败视为离线
  • 任务执行流程：获取列表 → 领取任务 → 入会 → 上报状态 → 定时心跳 → 完成任务
